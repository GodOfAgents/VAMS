# VAMS Six Hats Prompts

Blue Hat:

- What decision is being made?
- What subsystem and roadmap phase are involved?
- What would make the answer actionable?

White Hat:

- Which claims are verified by code, tests, docs, or deployment evidence?
- What is unknown?
- Are docs stale relative to source?

Black Hat:

- Which invariants can break?
- Where can mock mode leak?
- What is the worst credible exploit, deployment failure, or economic abuse?

Yellow Hat:

- What capability, security margin, or roadmap progress improves?
- Does it reduce centralization or increase verifiability?

Green Hat:

- What simpler, safer, or more testable design exists?
- Can a prototype de-risk the idea before protocol change?

Red Hat:

- What feels brittle, confusing, or strategically misaligned?
- How would builders, node operators, auditors, or regulators react?
