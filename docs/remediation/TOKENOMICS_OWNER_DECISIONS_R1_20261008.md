# Restricted-testnet economic decision memo R1

Date: 2026-10-08. Status: **owner decisions requested; no interpretation accepted**. This memo translates the source-backed [tokenomics gap map](TOKENOMICS_HARDENING_RECONCILIATION_R1.md) into bounded choices. It changes no contract, control disposition, activation policy or invariant. The source map is triage, not executable acceptance.

The restricted profile is faucet-only on Polygon Amoy and Cardano Pre-Prod. Preserve the absolute $1 \times 10^9$ token supply cap (INV-8), zero staking rewards, no staking minter, and disabled Deposit, Slash activation and ExecuteIntent. Excluding a future feature requires reviewed profile scope and executable containment; deployment-script intent alone is insufficient.
