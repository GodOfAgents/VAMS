# F04 owner recovery and rotation design assessment — 2026-10-04

The owner selected `agent_nft.agent_nft.mint` as the normative identity-NFT path. The selected path is a target architecture, not current behavior: at canonical HEAD `829ab544571f12efe50ecb5740f129c8acb3e16f`, the standalone mint handler rejects every redeemer; registry-side mint and burn branches remain active. This design keeps the identity path standalone, prohibits registry-side minting, and defines owner/controller recovery before source implementation.

The design sets a fixed 3-of-5 guardian authority. Routine controller rotation requires the current controller, two guardians, and the destination controller’s transaction signature, with a 48-hour delay. Lost/compromised controller recovery requires three guardians and the new controller’s transaction signature, immediately freezes ordinary actions, waits seven days, and does not require or permit a veto by the old controller. Emergency freeze is immediate at 3-of-5; unfreeze requires 3-of-5 and 48 hours. Guardian rotation requires 3-of-5 old guardians and signatures from all five proposed guardians, with a 14-day delay. Cancellation requires 3-of-5; pending requests expire permissionlessly without authority transfer. Voluntary deregistration requires controller plus 3-of-5 and a 48-hour delay, with an exact terminal burn and controller payout.

The design defines identity, request-ID, and destination-commitment byte encodings; DID bytes retain current 32–256-byte valid UTF-8 bounds. It binds pending actions to a monotonic nonce and controller/guardian epochs, rejects counter overflow rather than wrapping, freezes compromised identities immediately, preserves independently authorized slash handling under the separate F05 activation/value rules, and requires downstream TEE/session/OMS/cache credentials to reject stale controller epochs. It prohibits unilateral administrator takeover and silent V1-to-V2 migration.

The 31 targeted tests are specified but were not executed; implementation tests, compiled evaluator behavior, ledger admission, and live-network evidence remain unverified.
